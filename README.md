# PRINCE RETAIL — SABAY SA BUHAY

> **Official Brand Slogan**: *"SABAY SA BUHAY"*  
> **Corporate Identity**: Premium, minimalist, modern e-commerce and corporate web portal for Prince Retail Group of Companies.  
> **Creator / Architecture Credit**: `DECStudioAiCreation`

---

## 🛍️ Overview

**Prince Retail** is a leading Philippine supermarket, hypermart, and wholesale retail chain founded in 1990 by **Robert Lim Go**. Dedicated to the core mission **"TO SERVE THE UNDERSERVED"** and guided by the vision **"OTOP — ONE TOWN, ONE PRINCE"**, Prince Retail brings quality, affordable groceries and essentials to more than 85% of Filipino households at the base of the socioeconomic pyramid across **Luzon, Visayas, and Mindanao**.

This repository contains the complete corporate and e-commerce web application, built with modern frontend architecture, pastel corporate aesthetics, interactive animations, and responsive mobile-first design.

---

## ✨ Features & Architecture

### 1. Hero Experience & Mobile App Showcase
* Elegant typography with brand slogan **"SABAY SA BUHAY"**.
* Interactive mobile app mockup featuring the official Prince mobile application screens in sequence (1 to 8).
* Quick CTAs for Online Grocery Shopping, Store Locator, and Royalty Rewards registration.

### 2. Comprehensive About Us & Heritage
* **History**: From the pioneering 1990 converted warehouse with a single cash register in North Reclamation Area, Cebu, to the Sari-Sari Store Society (SSS), and complete general merchandise expansion.
* **Corporate Profile**: Prince Hypermart one-stop model, second-generation executive leadership, and eco-sustainable green stores.
* **Vision & Mission**: Detailed **OTOP (One Town, One Prince)** and **"To Serve the Underserved"** pillars.
* **OPTIC Core Values**: Interactive accordion for **O**wnership, **P**ursuit of Excellence, **T**eamwork, **I**ntegrity, and **C**ost-Benefit Mindset.
* **Impact & Growth Metrics Dashboard**:
  * 📈 **1990 Growth Line Chart**: 36-year upward expansion curve from 1 cash register to 70+ stores.
  * 📊 **85%+ Demographic Bar**: Stacked demographic visualization of classes C, D & E market focus.
  * 🗺️ **70+ Regional Stores Bar Chart**: Tri-island distribution (Visayas 60%, Mindanao 28%, Luzon 12%).
  * 🎯 **100% Radial Gauge Ring**: Circular progress indicator celebrating commitment to OTOP.

### 3. Royalty Rewards Loyalty Program & Digital Pass Wallet
* **Segmented Pill Navigation**: Dedicated tier viewer for `ROYALTY`, `ROYALTY GOLD`, `ROYALTY PLATINUM`, and `ROYALTY DIAMOND`.
* **Authentic Physical Card Imagery**: High-resolution official gift cards embedded directly.
* **Interactive 3D Wallet Pocket**:
  * 4 pass cards tucked at natural fan angles (`-4.5°`, `-1.5°`, `+1.5°`, `+4.5°`) inside a stitched leather wallet sleeve.
  * Cards smoothly rise upward on hover/focus to reveal barcode lines, tier multipliers, and registration actions.
  * **3-Second Autoplay Rotation**: Cards automatically cycle and pull out sequentially every 3 seconds, automatically pausing on user hover/tap.
* **Instant Digital Card Registration**: In-app modal with instant SMS activation flow and ₱150 shopping vouchers.

### 4. Customer & Enterprise Programs
* Segmented horizontal pill menu to reduce page scrolling:
  * 🎁 **GC Rebate**: Volume-tiered gift certificate rebate program.
  * 💼 **PO Cash Bond**: Business guarantor program with attractive returns.
  * 📦 **Layaway Plan**: Zero-interest flexible installment savings.
  * 🌾 **Papuno Puhonan**: Sari-sari store capital enhancement financing.
* Interactive calculators for rebates, guarantor returns, and layaway schedules.

### 5. Online Supermarket & E-Commerce Cart
* Fast shopping catalog with category filters (*Daily Essentials, Pantry Favorites, Home & Living, Fresh & Chilled, Personal Care, Kasosyo Bulk*).
* Search modal with instant autocomplete and quick price lookups.
* Interactive sliding cart drawer with quantity adjustment, promo code voucher system, free delivery progress bar, and **"Clear All"** one-click cart emptying.

### 6. Store Locator
* Interactive search and regional filtering for stores across **Luzon, Visayas, and Mindanao** with operating hours, phone numbers, and amenities.

### 7. Careers & Contact
* Departmental job openings and streamlined application submission modal.
* Customer care inquiry channels, headquarters address, and branch directory.

## 🚀 Getting Started

### Prerequisites
* Node.js (v18.0.0 or higher recommended)
* npm (v9.0.0 or higher)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/DECStudioHub/PrinceRetail.git
   cd PrinceRetail
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Lint and type-check**:
   ```bash
   npm run lint
   ```
